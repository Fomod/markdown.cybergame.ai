Md Previewをインストールし、Filesまたは共有シートからファイルを開くと、iPhone/iPad上でローカルにプレビューできます。 ChatGPT、Claude、Gemini、Perplexity、Copilot、DeepSeek、Grok、NotebookLM、Obsidian、Notion、GitHub、メール、iCloud Drive、Google Drive、Dropbox からの Markdown ファイルを Md Preview で表示できます。 サブスクリプションなし。アプリ内課金なし。広告なし。

この方法が向いている場面

すでにファイルがあり、iPhoneやiPadで確実にプレビューしたいときの最短ルートです。

一致する検索意図

Perplexityから受け取ったMarkdownファイルがあり、iOSではアイコン、ソース、または読みにくい表示になっている場合です。

iOSの標準ルート

Files、メール、Safariのダウンロード、AirDrop、クラウド、元のアプリから開き、共有またはOpen Inを使います。

ビューアの役割

Md Previewは.md, .markdown, .mdx, .rmd, .qmd用のローカルビューアです。アップロードや変換サイトを挟まずに開けます。

使わなくてよい場合

プレーンテキストで十分ならFilesで表示できる.mdファイルもあります。Markdown、コード、数式、表、Mermaidをレンダリングしたい場合にMd Previewを使います。

ファイルがHTMLの場合

MarkdownではなくHTMLが生成された場合は、関連するiOSビューアのHtml Previewを使います。
