最匹配的搜尋意圖

你已經有一個來自離線檔案的 Markdown 檔案，但 iOS 只顯示圖標、原始碼或不完整預覽。

iOS 原生路徑

先從 Files、郵件、Safari 下載、AirDrop、雲端硬碟或來源 App 開啟，再使用分享或開啟方式。

預覽工具的作用

Md Preview 是 .md, .markdown, .mdx, .rmd, .qmd 的本機專用預覽工具，避免上傳檔案或使用轉換網站。

什麼時候不需要它

如果只看純文字就夠，Files 可以顯示很多 .md 檔案。需要渲染 Markdown、程式碼、數學公式、表格或 Mermaid 時，再用 Md Preview。

如果檔案其實是 HTML

當這個工作流產生的是 HTML 而不是 Markdown，請使用配套 iOS 預覽工具 Html Preview。
