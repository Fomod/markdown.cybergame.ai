Cuándo esta es la solución correcta en iOS

Usa esta ruta cuando ya tienes el archivo y necesitas una vista previa fiable en iPhone o iPad.

Intención de búsqueda principal

Tienes un archivo Markdown de adjuntos de email, chat y equipos y iOS muestra un icono, código sin renderizar o una vista poco legible.

Ruta nativa de iOS

Empieza en Files, Mail, descargas de Safari, AirDrop, una nube o la app de origen, y usa Compartir u Open In.

Papel del visor

Md Preview es el visor local dedicado para .md, .markdown, .mdx, .rmd, .qmd; evita subidas y flujos de conversión.

Cuándo no hace falta

Si basta con texto plano, Files puede mostrar muchos archivos .md. Usa Md Preview cuando necesites Markdown renderizado, código, matemáticas, tablas o Mermaid.

Si el archivo es HTML

Usa Html Preview, el visor iOS complementario para HTML, cuando el flujo produce HTML en vez de Markdown.

Siguiente acción

Abre la ficha de App Store, instala el visor, vuelve al archivo y compártelo con Md Preview.
