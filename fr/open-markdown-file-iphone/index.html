Quand cette solution iOS convient

Utilisez ce parcours quand le fichier existe déjà et doit être prévisualisé de façon fiable sur iPhone ou iPad.

Intention de recherche visée

Vous avez un fichier Markdown venant de outils IA, Files, e-mail, téléchargements ou cloud et iOS affiche une icône, du code brut ou une prévisualisation peu lisible.

Parcours iOS natif

Partez de Files, Mail, des téléchargements Safari, AirDrop, d'un cloud ou de l'app source, puis utilisez Partager ou Ouvrir dans.

Rôle du lecteur

Md Preview est le lecteur local dédié pour .md, .markdown, .mdx, .rmd, .qmd; il évite l'envoi de fichiers et les convertisseurs.

Quand ce n'est pas nécessaire

Si le texte brut suffit, Files peut afficher beaucoup de fichiers .md. Utilisez Md Preview pour le rendu Markdown, le code, les maths, les tableaux ou Mermaid.

Si le fichier est HTML

Utilisez Html Preview, le lecteur iOS complémentaire pour HTML, quand le flux produit HTML au lieu de Markdown.

Action suivante

Ouvrez la fiche App Store, installez le lecteur, revenez au fichier puis partagez-le vers Md Preview.
