使用方式

儲存來源檔案

先儲存來自iCloud Drive的 Markdown 檔案，並確認原始 .md, .markdown, .mdx, .rmd, .qmd 檔案還在 Files、郵件、下載目錄或來源 App 中。

開啟 iOS 分享選單

在 iCloud Drive 或 Files 中開啟 Markdown 檔案，點擊分享，選擇 Md Preview，然後在 iPhone 或 iPad 上本機預覽。

選擇預覽 App

在分享目標中選擇 Md Preview，然後在 iPhone 或 iPad 本機開啟 iCloud Drive 中的 Markdown 檔案。

預覽並檢查

這個流程適合來自 iCloud Drive 的真實 .md、.markdown、.mdx、.rmd 或 .qmd 檔案。預覽前請把關聯圖片、CSS 或素材資料夾保留在檔案旁边。

為什麼這個 Markdown 場景在 iOS 上會卡住

iCloud Drive 可以儲存用於筆記、README、檔案、連結、圖片和表格的 Markdown 檔案。檔案能同步到 iPhone，但當目標是閱讀格式化後的檔案，而不是原始 Markdown時，iOS 仍可能需要專門的本機檢視工具。
