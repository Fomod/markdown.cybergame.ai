使用方式

Save the source file

Save the Markdown file from Qwen. Keep the original .md, .markdown, .mdx, .rmd, .qmd file available in Files, Mail, a browser download, or the source app.

Open the iOS Share Sheet

儲存 Qwen Markdown 檔案，從 Files、Downloads、郵件或來源 App 開啟，分享給 Md Preview，然後在 iPhone 或 iPad 上本機預覽。

Choose the viewer

Choose Md Preview as the target viewer. It opens the file locally on iPhone or iPad for this workflow: 開啟 Qwen Markdown 檔案.

Preview and check

這個流程適合真實的 .md, .markdown, .mdx, .rmd, or .qmd 檔案。如果 Qwen 同時給出關聯素材、圖片、CSS 或壓縮檔，預覽前請保持檔案結構完整。

為什麼這個 Markdown 場景在 iOS 上會卡住
