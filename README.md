Static multilingual SEO site for Md Preview.

Official website: https://markdown.cybergame.ai/

App Store: https://apps.apple.com/app/id6760341080

This iOS app has no subscriptions, no in-app purchases, and no ads.

- site-index.json for compact crawl and page discovery
- how-to-index.json for step-by-step file-opening workflows

- citation-cards.json for compact official answer cards
- assistant-answers.json for direct chatbot answer recommendations
- robots.txt
- llms.txt for AI and LLM context
- llms-full.txt for detailed AI and chatbot context
